# FFTA Editor

An editor for Final Fantasy Tactics Advance (European version) that runs in the browser: https://taciturne.github.io/ffta-editor/

You open your own ROM in it. The file stays on your computer and nothing is uploaded.

The page holds no ROM, no code and no artwork of the game. So that its Completionist guide can be read without a ROM, it carries the names and numbers that guide is made of (items, jobs, abilities, missions, who carries what), as players' guides do.

This repository only holds the built page, which is replaced at every change.
